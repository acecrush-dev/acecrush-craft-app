04 · 穿线记录 ​

4 个功能中的第 3 个。每次穿线写一条 + 到点提醒。

它能做什么 ​

每支球拍 详情页 上的"穿线记录"Tab。每条记录是一次穿线：

  • 日期
  • 线材（主 / 横）
  • 磅数（主 / 横）
  • 穿线师（选填）
  • 备注
  • 来源 ——「手动」/「来自 05 · 张力换算」（如果是张力换算跳转来的）

最新一条的日期同时驱动该球拍列表页上的"上次穿线"戳记。

录一次穿线 ​

进入某支球拍详情 → 穿线记录 Tab：

  1. + 添加穿线记录
  2. 录入：
字段默认说明
日期今天过去的日期也行
线材主空下拉（预置线材库：Yonex BG65 / BG80、Wilson NXT、聚酯系列等）；可自填
线材横空选填；单线打法留空
主磅数沿用球拍档案lbs 或 kg；可临时覆盖
横磅数沿用选填
穿线师空自由文本
备注空"手胶 2 层 / 减震 1 个 / 拉了 30 分钟"
来源手动若通过 第 5 章 跳入，自动标为「来自张力换算」
  1. 保存

不知道线材型号？ 进穿线日志 → 线材库 看我们预置的几百款；找不到可自填。

线材库 ​

下拉背后是一个离线数据库：

  • 品牌：Yonex、Wilson、Babolat、Head、Prince、Luxilon、Tecnifibre…
  • 类型：多股尼龙 / 聚酯 / 肠线 / 混合
  • 每条：典型打球寿命（小时）、推荐磅数区间

按类型筛选可以只看"你真用过的"。

换线提醒 ​

方式 A · 按时间 ​

最简单的：每个 N 天提醒一次。

  • 设定 N（默认 90，可选 30 / 60 / 90 / 120 / 180）
  • 提醒时间窗（默认 09:00，可改）
  • 触发后会自动归档"上次穿线"日期，下次提醒从那一天起算

方式 B · 按打球小时数 ​

更精细：估算你每周打球 × 时长 → 折算到总打球小时，达到目标数（比如 80 小时）就提醒。

  • 每周打球频率（次）
  • 每次平均时长（小时）
  • 目标打球小时数（默认 80 小时 / 线；横线建议 60 小时）
  • 线材类型系数（多股尼龙 1.0；聚酯线 0.7；肠线 0.5）—— 聚酯比尼龙更不耐磨，所以系数更低

例：每周 3 次 × 2 小时 = 6 小时/周，尼龙 1.0 → 80 / 6 ≈ 13 周 ≈ 3 个月。

App 内有"竖线、横线分别提醒"开关（方式 B 适用）。

提醒长什么样? ​

Android 系统通知：

┌──────────────────────────────────────┐
│ 🏸 AceCrush Craft        9:00 AM    │
│                                      │
│ "主力 Blade" 该换线了                │
│ 上次穿线：2026-04-15，已过 92 天     │
│                                      │
│ [稍后提醒] [查看] [标记已换]            │
└──────────────────────────────────────┘
  • 标记已换 → 自动跳到「添加穿线记录」页（填日期就行，旧记录归档）
  • 稍后提醒 → 推后 24 小时
  • 查看 → 跳到该球拍详情页

常见问题 ​

磅数可以从张力换算里直接带过来吗? ​

可以！这正是 05 · 张力换算 的设计。在张力换算结果页，点 「用此张力记录穿线」，App 会直接跳进「添加穿线记录」表单 —— 磅数预填、球拍预选、来源标为「来自张力换算」。

提醒被系统关掉怎么办? ​

进系统 设置 → 应用 → AceCrush Craft → 通知，把"允许通知"开回来。 进 App 「我的」Tab → 通知与提醒，把所有开关重置。

线材库在哪? ​

App 内离线，App 升级时同步更新；你也可以自填型号。

同一支拍一个月穿了两次，都要录吗? ​

每次穿线一条独立记录。提醒默认基于"最新一次"。

删除一支球拍? ​

进入详情页 → 右上角 ··· → 删除球拍。

删除时所有穿线记录会一起删除（无悬空数据）。再提醒一次：这些数据只在本机，没有云备份——请提前到 设置 → 导出 → JSON 备份。
