09 · 反馈 ​

我的 → 发送反馈，分类（Bug / 建议 / 其他）+ 文本（最多 2000 字）。

每条反馈附带：

  • App 版本号（如 V1.0.2 build 2026-08-30）
  • 系统版本（Android 14 / API 34）
  • 设备型号（如 Xiaomi 14）
  • 屏幕分辨率 / DPI
  • 反馈提交时刻

不附带你的账号、地理位置、相册、握把测算历史等任何私人数据。

反馈发起后 → 后台工单 → 团队排期内回复。如需更新，App 内 我的 → 反馈历史 看回信。

报告 Bug 模板 ​

如果你要发邮件，手动抄送以下信息会加速排查：

App 版本: V1.0.x build xxx
设备: <型号 + Android 版本>
复现步骤:
  1. ...
  2. ...
期望行为:
实际行为:
截图: <附件>
日志: <从手机文件管理 / Android/data/com.acecrushcraft.app/files/logs 取 .log>

联系 ​

  • 邮箱：acecrushdev@gmail.com
  • 小红书：@AceCrush

邮件通常 1–3 个工作日内回复。小红书评论不是反馈渠道。
