03 · Rackets (Profile) ​

Feature 2 of 4. Record each racket you own — brand, model, headsize, length, weight, balance, tension target — all on-device.

What it does ​

A "racket collection" page on the Rackets tab. Each card shows the racket's photo (if set) and a one-line summary:

  • Cover photo (optional)
  • Name
  • Brand · Model
  • Headsize
  • Last restring date

+ Add racket opens a form; the card's menu offers Edit / Delete / Set reminder.

Add a racket ​

  1. Rackets tab → + Add racket
  2. Fill the form (minimum 4 fields, others optional):
FieldRequiredNotes
Name✅e.g. "Main Blade" / "Backup Pro Staff"
Brand✅Dropdown; can be custom
Model✅Dropdown; can be custom
Headsize✅Number + unit (default in²)
Length❌Default 27"
Strung weight❌g or oz
Balance❌mm or in
String tension main / cross❌main / cross; can fill later
Notes❌"Birthday gift / bought in 2019", etc.
Cover photo❌Pick from gallery or take a photo
  1. Save

Added rackets show on Rackets tab as cards.

Detail page ​

Tap any racket card to open the detail page. Four tabs:

TabWhat you do here
ProfileSpecs (read-only display of the form you filled; tap Edit to change)
Stringing logAll restring records (see 04 · Stringing log)
ReminderSet or edit a restring reminder (see 04 · Stringing log)
NotesFree-text notes you've added

The detail page also has Edit (top-right) and Delete (overflow menu).

Specs 101 ​

Head Size ​

V1.0's default unit is square inches. Quick reference:

Headsize (in²)Style
95–98Control (small head)
98–100Neutral
100–104Forgiving
104–115Oversize / recreational

Note: the 4-bucket table above is a playstyle reference only. For DT ⇄ RT calculation in 05 · Tension Conversion the App collapses any headsize into 3 buckets that match the ERT300 reference machine's DT anchor table — MID 83–94 / MID+ 95–105 / OVER 106–115 sq.in. You only need to pick the right bucket when using the tension converter.

Strung Weight ​

Look up "strung weight" for the model online.

Range (g)Style
< 300Very light (attacking)
300–320Standard
320–340Control
> 340Heavy / powerful

Balance ​

  • In mm (more precise) or in
  • Most rackets sit at 320–340 mm (even balance ~320 mm; head-light below; head-heavy above)

Why a profile? ​

  • Set up once: the next restring record pre-fills the racket's tension target, headsize, etc.
  • Reminder context: a reminder knows which racket to refer to ("Main Blade is due")
  • Cover photo: makes the list scannable when you own 5+ rackets

Common questions ​

I have 10 rackets — too many cards to scroll? ​

The Rackets tab list supports swiping between cards (phone) or scrolling (tablet). You can also pin up to 4 rackets to the top via long-press.

Cover photo is required? ​

No, it's optional. Rackets without a cover photo render as a placeholder card with the brand initial.

Where does the "last restring date" come from? ​

It's the most-recent record on the racket's Stringing log tab.

What's next? ​

A racket profile without any restring records is just a name. Record a restring → see 04 · Stringing log.

Or skip that: jump straight to the calculator — see 05 · Tension conversion for converting DT ⇄ RT ⇄ lbs ⇄ kg, with a one-tap Use this tension → log stringing handoff back to chapter 04.
