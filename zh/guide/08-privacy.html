08 · 隐私 & 许可 ​

隐私与权限清单 ​

权限何时申请用作是否可以拒绝
通知首次启动换线提醒可以（关了就收不到提醒）
相机V1.1 拍照测握把拍手掌可以（改用手动校准）
相册 / 文件用户主动「保存到相册」导出图可以（改用「分享到」流程）
网络第一次需要时反馈发送关了 → 反馈延迟到开网

这份清单是 V1.0+ 完整权限要求。"网络"权限只在用户主动发送反馈时使用，默认不上传。

历史定位 / 通讯录 / 通讯录 / 设备 ID / IMEI —— 全部不申请。

开源许可 ​

内嵌的 MediaPipe 及其 Pose / Hand 模型都遵循 Apache License 2.0。完整文本在 我的 → 开源许可，打包成 Assets bundle，可离线查看。

字体使用系统默认（Roboto / SF Pro / PingFang），不打包第三方字体。

第三方组件 ​

仅含开源依赖（MediaPipe + 一两个 Dart 包）。详细列表见 我的 → 第三方组件。
