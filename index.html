English | 简体中文

What is this? ​

AceCrush Craft is a tennis-equipment data tool for racket sport enthusiasts — not another "tennis community app", but a small, offline-first utility that bundles the four everyday calculations and records players actually use:

#FeatureWhat you get
1AI grip sizePalm photo → recommended grip size in Yonex / Wilson / Head-Prince-Babolat systems
2Racket profileRecord specs & notes for every racket you own
3Stringing logOne record per restring, with automatic reminders
4Tension conversionDT ⇄ RT ⇄ lbs ⇄ kg cross-calculator; tap "Use this tension" to send the result straight into the stringing log

All data lives in the device's local SQLite — no upload, no network. AI grip measurement activates only when you press the camera shutter, and runs on-device by default.

📥 Download ​

Currently supported platforms: Android (iOS version is not yet released).

Latest release: V1.0.x

Download link: https://github.com/acecrush-dev/acecrush-craft-app/releases

Each release ships app-release.apk + a SHA-256 checksum.

Install note: Android blocks "unknown sources" the first time. Go to Settings → Apps → Special app access → Install unknown apps → Allow from this source, then tap the APK again.

iOS users: there is no available build yet — please bookmark acecrush.dev to get notified at launch.

🚀 Quick start ​

After installing V1.0, the minimum getting-started path:

  1. Open 01 · Getting Started and grant permissions + notification
  2. Try 02 · Grip Size Measurement once with a palm photo (or a ruler)
  3. Add one main racket in 03 · Rackets and set a renewal reminder via 04 · Stringing Log
  4. Convert tension units whenever you need it: 05 · Tension Conversion → tap "Use this tension → log stringing" to drop the result straight into a restring record

🔒 Privacy promise ​

  • All personal data stays on-device (SQLite inside the app sandbox). Uninstall ⇒ wiped
  • No upload of your sports data — stringing logs, grip measurements, and tension-conversion results never leave your phone
  • AI grip measurement: runs MediaPipe entirely on-device; the image never leaves your phone
  • Full manifest: 08 · Privacy
