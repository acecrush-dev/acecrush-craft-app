主题与显示 ​

项选项默认
主题跟随系统 / 浅色 / 深色 / OLED 纯黑（V1.1+）跟随系统
单位公制 / 英制 / 双单位并列公制
字体大小标准 / 大 / 超大标准

OLED 纯黑：把背景换成 #000000，省电、深色模式更纯净。

数据管理 ​

导出 JSON ​

我的 → 数据管理 → 导出 → 选要导出的范围（球拍档案 / 穿线日志 / 握把测算历史 / 全部）→ 生成 .json 文件 → 系统分享面板。

该文件不加密，里面就是你的私人数据。请用邮件发给自己、AirDrop 给自己的电脑 / 保存到加密云盘。别发朋友圈。

导入 JSON ​

我的 → 数据管理 → 导入 → 选一份 JSON。重复的条目（按 ID 匹配）会被跳过，不会覆盖你现有数据。

删除全部数据 ​

我的 → 数据管理 → 删除全部数据。需要二次确认。

删完不可恢复（虽然前面你要么已经导出，要么就是不要这个数据了）。

通知 ​

项默认说明
换线提醒开启需要系统层允许通知
提醒时间窗09:00你可以选 09:00 / 12:00 / 20:00
提前几天提前 3 天到期前 3 天、1 天、零天 各推一次

如果通知被关掉，进系统 设置 → 应用 → AceCrush Craft → 通知 重新开启后回 App 重置。
