01 · 快速开始 ​

从零打开 V1.0 到完成「第一次穿线提醒」，大约 5 分钟。

安装 ​

安装 APK（Android） ​

  1. 在「下载」页面选一个来源，下载 app-release.apk
  2. 第一次打开 APK，Android 会拦截"未知来源应用"：
    • 设置 → 应用 → 特殊权限 → 安装未知应用
    • 选中你的浏览器 / 文件管理器，把"允许此来源"打开
  3. 重新点击 APK → 仍要安装 → 完成

iOS 用户：当前没有可用构建，详见 00 · 项目介绍。

启动 ​

点击桌面图标进入 AceCrush Craft。首次启动会做三件事：

  1. 初始化本地 SQLite 数据库（球拍档案、穿线日志）
  2. 申请"通知"权限（用于换线提醒）
  3. 直接进入首页 —— 没有账号，不登录

通知被拒绝？别担心 —— 你可以在 设置 → 通知 中重新开启，但没有通知就没有换线提醒。

首页 —— 四大功能 ​

首页布局是顶部两张大卡片 + 中下方的功能宫格：

顶部卡片它做什么
AI 测握把尺寸拍一张手掌照片 → 推荐握把尺寸
张力换算DT ⇄ RT ⇄ lbs ⇄ kg 互转

功能宫格里：

  • AI 测握把尺寸 — 与顶部卡片一样
  • 球拍档案 — 你的全部球拍
  • 穿线记录 — 穿线历史 + 换线提醒
  • 张力换算 — 与顶部卡片一样
  • 设置 — 主题 / 单位 / 隐私 / 反馈 / 开源许可

长按宫格的图标拖到顶部卡片就能换顺序；长按拖出宫格变回卡片。顺序只在你这台设备上生效。

把通知打开（最关键的一步） ​

不打开通知 → 换线提醒推送不到。强烈建议在第一时间做完：

  1. 进「我的」Tab → 通知与提醒
  2. 把"换线提醒"打开 → Android 系统设置里允许本 App 发送通知
  3. 设置提醒时间窗（默认 09:00，可改 20:00 / 12:00）

如果你以后不想收到通知，再来关掉就好。

三栏 Tab ​

Tab你在这里做什么
首页四个功能入口（大卡片 + 宫格）+ 当日提醒
球拍档案列表、穿线日志、提醒设置
我的主题 / 语言 / 单位 / 隐私 / 反馈 / 开源许可

走一遍：加第一支球拍 + 录一次穿线 ​

这是最短的"用起来"路径：

第 1 步 —— 加球拍（03 · 球拍档案） ​

  1. 「球拍」Tab → + 添加球拍
  2. 录入最少 4 项：名称、品牌、型号、拍面
  3. 选填：长度 / 重量 / 平衡点 / 备注
  4. 保存

第 2 步 —— 录穿线（04 · 穿线记录） ​

  1. 进入该球拍详情 → 穿线记录 Tab → + 添加穿线记录
  2. 录入：日期（默认今天）、线材、主磅 / 横磅，可填穿线师 / 备注
  3. 保存

第 3 步 —— 设换线提醒 ​

紧接上一节，在球拍详情页：

  1. 设置穿线提醒 → 选规则：
    • 按时间（默认 90 天后）
    • 按打球小时数（你每周打球 × 时长 → 估算）
  2. 选提醒时间窗（用回上面设的那个）

不在 App 里登记任何数据？提醒仍然到点响，但就是空消息（"是时候看看你的拍线了"）。

切换主题与单位 ​

「我的」Tab：

  • 主题：跟随系统 / 浅色 / 深色（V1.1 起支持纯黑 OLED）
  • 单位：长度 = 毫米 / 英寸；重量 = 克 / 盎司；磅数 = lbs / kg
  • 语言：简体中文（V1.0）+ English（V1.0+）

语言设置只影响 App 显示语言；不会翻译你录入的备注、拍名。

第一次反馈 ​

「我的」Tab → 反馈与建议：

  • 一句话描述问题 → 发送
  • 反馈会带 App 版本号与设备基本信息（OS 版本 / 屏幕分辨率，不带任何账号信息或你录入的数据）

详见 06 · 反馈。

常见问题 ​

卸载了再装数据还在吗? ​

不在。所有数据存在 App 沙盒目录（Android: /data/data/com.acecrushcraft.app/databases/），卸载即清空。 建议安装 V1.1 之前，先在「设置 → 导出」做一次 JSON 备份。

iOS 什么时候有? ​

暂无 ETA。先把 Android V1.0 / V1.1 打磨到位，iOS 计划中。

关闭网络可以用吗? ​

除以下这类外可以：

  • 反馈发送

详见 00 · 三大基石之离线优先 与 06 · 隐私与权限清单。
