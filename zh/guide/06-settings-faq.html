主题与显示 ​

项选项默认
主题跟随系统 / 浅色 / 深色 / OLED 纯黑（V1.1+）跟随系统
单位公制 / 英制 / 双单位并列公制
字体大小标准 / 大 / 超大标准

OLED 纯黑：把背景换成 #000000，省电、深色模式更纯净。

数据管理 ​

导出 JSON ​

我的 → 数据管理 → 导出 → 选要导出的范围（球拍档案 / 穿线日志 / 握把测算历史 / 全部）→ 生成 .json 文件 → 系统分享面板。

该文件不加密，里面就是你的私人数据。请用邮件发给自己、AirDrop 给自己的电脑 / 保存到加密云盘。别发朋友圈。

导入 JSON ​

我的 → 数据管理 → 导入 → 选一份 JSON。重复的条目（按 ID 匹配）会被跳过，不会覆盖你现有数据。

删除全部数据 ​

我的 → 数据管理 → 删除全部数据。需要二次确认。

删完不可恢复（虽然前面你要么已经导出，要么就是不要这个数据了）。

通知 ​

项默认说明
换线提醒开启需要系统层允许通知
提醒时间窗09:00你可以选 09:00 / 12:00 / 20:00
提前几天提前 3 天到期前 3 天、1 天、零天 各推一次

如果通知被关掉，进系统 设置 → 应用 → AceCrush Craft → 通知 重新开启后回 App 重置。

隐私 & 许可 ​

隐私与权限清单 ​

权限何时申请用作是否可以拒绝
通知首次启动换线提醒可以（关了就收不到提醒）
相机V1.1 拍照测握把拍手掌可以（改用手动校准）
相册 / 文件用户主动「保存到相册」导出图可以（改用「分享到」流程）
网络第一次需要时反馈发送关了 → 反馈延迟到开网

这份清单是 V1.0+ 完整权限要求。"网络"权限只在用户主动发送反馈时使用，默认不上传。

历史定位 / 通讯录 / 通讯录 / 设备 ID / IMEI —— 全部不申请。

开源许可 ​

内嵌的 MediaPipe 及其 Pose / Hand 模型都遵循 Apache License 2.0。完整文本在 我的 → 开源许可，打包成 Assets bundle，可离线查看。

字体使用系统默认（Roboto / SF Pro / PingFang），不打包第三方字体。

第三方组件 ​

仅含开源依赖（MediaPipe + 一两个 Dart 包）。详细列表见 我的 → 第三方组件。

反馈 ​

我的 → 发送反馈，分类（Bug / 建议 / 其他）+ 文本（最多 2000 字）。

每条反馈附带：

  • App 版本号（如 V1.0.2 build 2026-08-30）
  • 系统版本（Android 14 / API 34）
  • 设备型号（如 Xiaomi 14）
  • 屏幕分辨率 / DPI
  • 反馈提交时刻

不附带你的账号、地理位置、相册、握把测算历史等任何私人数据。

反馈发起后 → 后台工单 → 团队排期内回复。如需更新，App 内 我的 → 反馈历史 看回信。

常见问题（FAQ） ​

1. App 是不是完全免费的? ​

是。无广告、无内购、无会员。

2. 升级到 V1.1 会收费吗? ​

不会。

3. 数据会被上传吗? ​

不上传，除非你点 反馈。

4. 我卸载了，数据恢复不了？ ​

是的，没云备份——见 04 · 数据迁移。

5. iOS 什么时候有? ​

暂无可用版本。详见 00 · 支持平台。

6. 启动后空白 / 卡死怎么办? ​

  1. 重启 App
  2. 若仍异常：我的 → 数据管理 → 删除全部数据（先把 JSON 导出）
  3. 还不行：卸载重装

7. 怎么把 App 图标放到桌面? ​

Android 安装后桌面会有图标。长按拖到文件夹里也行。

8. 我用了第三方启动器（如 Nova），图标不一样？ ​

Android 自适应图标在你启动器里可能渲染为不同形状，但功能不影响。

9. 可以导出为 PDF / Excel 吗? ​

V1.0 仅 JSON 导出。V1.1 起会加 CSV（适合 Excel）。

10. 我能贡献翻译吗? ​

暂未开放翻译协作。V1.0 起官方语言：简体中文 / English。

11. 这个项目会开源吗? ​

V1.0 上架后另行评估。当前不提供源代码 / 二进制构建脚本。

12. 我在测试中遇到 Bug，怎么报告? ​

最快：App 内 我的 → 发送反馈。 邮件：support@acecrush.dev（含日志截图）。

13. iOS Safari 链接到 App 会失败吗? ​

会。当前没有 iOS 版本，Universal Links 也没配置——直接打开官网即可。
