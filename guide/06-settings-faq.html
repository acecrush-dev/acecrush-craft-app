Data management ​

Export JSON ​

Me → Data → Export → pick the scope (racket profile / stringing log / grip history / all) → generates a .json file → system share sheet.

The file is not encrypted — it's your private data. Email it to yourself, AirDrop to your own computer, or save it to an encrypted cloud drive. Don't share it on social media.

Import JSON ​

Me → Data → Import → pick a JSON. Duplicate entries (matched by ID) are skipped; existing data is not overwritten.

Delete all data ​

Me → Data → Delete all data. Requires double confirmation.

Once deleted it's gone (your previous export is your only copy).

Open-source licenses ​

The bundled MediaPipe and its Pose / Hand models are licensed under Apache License 2.0. The full text is bundled in Me → Open-source licenses as Assets, available offline.

The App uses default system fonts (Roboto / SF Pro / PingFang); no third-party fonts are bundled.

Third-party components ​

Only open-source dependencies (MediaPipe + a couple of Dart packages). Full list: Me → Third-party components.

Feedback ​

Me → Send feedback. Categories (Bug / Suggestion / Other) + text (up to 2000 chars).

Each record includes:

  • App version (e.g. V1.0.2 build 2026-08-30)
  • OS version (Android 14 / API 34)
  • Device model (e.g. Xiaomi 14)
  • Screen resolution / DPI
  • Submission timestamp

Does not include your account (there is none), geolocation, photos, grip history, or any private data.

After submission → backend ticket → team replies in their queue. To follow up, go to Me → Feedback history.

Common questions (FAQ) ​

1. Is the App completely free? ​

Yes. No ads, no IAP, no premium tier.

2. Will V1.1 cost money? ​

No.

3. Is my data uploaded? ​

No, unless you tap Feedback.

4. After uninstall, can I recover data? ​

No — there's no cloud backup. See 04 · Data migration.

5. When is iOS coming? ​

No available build yet. See 00 · Supported platforms.

6. App launches blank / hangs — what now? ​

  1. Relaunch
  2. Still broken? Me → Data → Delete all data (export JSON first)
  3. Still broken? Uninstall + reinstall

7. How do I put the icon on the home screen? ​

Android places the icon at install. Long-press to drop into a folder if you'd like.

8. I use a third-party launcher (e.g. Nova) and the icon looks different? ​

Adaptive icons render differently across launchers; behavior is unaffected.

9. Can I export as PDF / Excel? ​

V1.0 is JSON only. V1.1+ adds CSV (opens in Excel).

10. Can I contribute a translation? ​

Not open yet. V1.0 ships in 简体中文 + English.

11. Will this project go open-source? ​

A decision will be made after the V1.0 store launch. Source code and build scripts are not currently provided.

12. I hit a Bug in testing — how to report? ​

Fastest: in-App Me → Send feedback. Email: support@acecrush.dev (attach screenshots).

13. Will iOS Safari deep-link to the App work? ​

It won't, because there's no iOS build and Universal Links aren't configured. Open the official site instead.
